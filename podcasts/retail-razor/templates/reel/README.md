# TRRS reel template (9:16 HyperFrames)

Clean copy of the CD-approved S6E15 R2 pilot (`episodes/S6E15_leslie-ann-hall/work/hyperframes/r2`) with all episode
media and episode scenes removed. Procedure: skill **trrs-reel**. Look and tokens: skill **trrs-style**.

## Use
1. Copy the whole folder to `episodes/<SxEyy_guest>/work/hyperframes/rN` (never edit the template in place).
   Rename `package.json` / `meta.json` name + id to `trrs_<sxeyy>_rN`.
2. Drop in the cut: `assets/video/aroll.mp4` (1920x1080 full episode frame, 30 fps CFR, crf 16, no audio) and
   `assets/audio/voice.wav` (48 kHz, -16 LUFS, exactly the A-roll length). `check` reports both as missing until then.
3. Captions: `python tools/build_captions.py --words <work/reels/rN/words.json> --out compositions/captions.html --end <outro start> --key "a,b,c"`
   (`tools/words.sample.json` only feeds the placeholder captions; delete it in the project).
4. Edit `index.html` at every `TEMPLATE` marker: shot list (one `<video>` per speaker shot), crops, punch-ins,
   b-roll, cards, sound; then `header.html` (duration + BROLL hide list), `tags.html` (names, start times),
   `outro.html` (only the two variables `ep_title`, `ep_show`).
5. `npx --yes hyperframes@0.8.217 check --json` -> 0 errors, then snapshot every shot change and look.

## Check status
Template as shipped: `check` reports exactly two lint errors, `audio_src_not_found` (voice.wav) and
`missing_local_asset` (aroll.mp4), because the episode media is intentionally absent. With placeholder media dropped in
(scratch test, 2026-11-02, dark placeholder video + silent voice) the full check returns ok: true with 0 errors. The only
warnings are the outro's `line_unread` (as on every S6E15 reel) and the silent placeholder voice. A bright test-pattern
placeholder triggers contrast errors on the name-tag role and the captions, which is expected because real footage is
dark. Accepted warnings with real footage are listed in the trrs-reel skill.
