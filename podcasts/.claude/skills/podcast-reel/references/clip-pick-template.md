# Clip picks for the CD (template)

Send this as a short list and wait for approval before cutting. Source times are **mp4 seconds** taken from `ep_words.json`, not show-notes timestamps.

```
<SHOW> <SxEyy> — reel picks (<guest>, release <date>)

R1  <working title>                         ~<NN> s   slot: <pre-release | launch | +N days>
    Angle: <one sentence a stranger would care about>
    Hook pattern: <bold claim | hidden method | personal question | identity belief | contradiction>
    Script (verbatim):
      HOST: "<...>"                          [<src in>–<src out>]
      GUEST: "<...>"                         [<src in>–<src out>]
    Cuts: <what is removed and why, e.g. false start, tangent, backchannel in a gap>
    Card/b-roll ideas: <literal visuals for the key lines>
    Flags: <unclear words, overlapping backchannels, guest stats that need attribution>

R2  ...

Alternates: <title — src time — one line why>
Suggested order: <R2 pre-release, R3 launch, then ...>
```

Before you send, check:
- [ ] Each pick has a different reason to care. Could a stranger sum each one up in one sentence?
- [ ] The payoff lands inside the clip, and the clip ends clean, with no trailing conversation.
- [ ] The host is present in at least some picks (a framing question or a reaction).
- [ ] Every word was checked against the audio (not the show notes), and the speaker was checked on video.
- [ ] Any statistic is the guest's own claim and stays attributed to the guest.
- [ ] None of the guest's or client's customers or partners would appear as a negative example.
